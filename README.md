# 🌱 IGLM — Software y Asesoría Agrícola

Sitio web profesional de **Lucas Mateo Tabares Franco** — Ingeniero Agrónomo (Universidad de Caldas) y extensionista de la Federación Nacional de Cafeteros en Sevilla, Valle del Cauca, Colombia.

Aquí viven las páginas públicas de sus proyectos: las apps de gestión agrícola, el proyecto Finca Cafetera y las páginas legales (privacidad y términos) que usan las aplicaciones.

🌐 **Sitio**: https://iglm.github.io

## 📱 Apps

| App | Descripción | Tecnología |
|---|---|---|
| ☕ **Finca Cafetera** | El libro digital de la finca cafetera: lotes, labores, recolección, beneficio, ventas e inventario, con costo por arroba y punto de equilibrio | TanStack Start + React + TS |
| 🌿 **Monitoreo Broca y Roya** | Evaluación árbol por árbol de broca y roya en café | React + TS + Capacitor |
| 📋 **Programador de Labores** | Planificación agrícola multi-cultivo | React + TS + Capacitor |
| 🛒 **CompraCafé** | Gestión de compras de café con margen P&L | Android nativo (Jetpack Compose) |

## 📚 Libros

- 🧪 **Ácidos húmicos en Colombia** — libro técnico sobre producción de humatos desde leonardita con KOH y su uso en café, aguacate y plátano/banano, con evidencia verificada y fichas de campo.
- 🍌 **El cultivo del plátano** — libro técnico del cultivo con alcance mundial para el lector colombiano, con énfasis en la asociación plátano–café.
